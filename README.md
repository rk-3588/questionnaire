# 大学生婚恋意愿调查系统

一个面向匿名填写、汇总展示与轻量画像比较的婚恋意愿调查网站。参与者以 20 道五级量表题建立匿名档案，可选择昵称、性别标记和留言；系统将回答整理为六维画像，并展示与其他匿名档案的相似度。

> 本项目基于 [LBEILC/RhineLabUI](https://github.com/LBEILC/RhineLabUI) 二次开发。原项目提供了三维交互终端的视觉与技术基础；本项目已将产品目标由游戏视觉复刻改为婚恋意愿调查与匿名档案系统。

## 功能

- 20 道婚恋意愿五级量表题，覆盖关系意愿、自主选择、未来规划、现实压力、风险意识和责任协商。
- 匿名档案：昵称可留空，系统会生成访客名称；支持可选性别标记与 120 字以内留言。
- 六维雷达画像：将回答转化为可阅读的个人倾向概览，不输出诊断、预测或价值判断。
- 匿名匹配：以 20 题答案的平均差异计算 0–100% 相似度，仅作浏览参考。
- 三维档案界面：问卷档案与既有交互场景联动，远端数据会优先写入档案池。
- 本地优先：接口暂不可用时，浏览器仍保留本地填写记录；恢复联网后可继续读取公共档案索引。

## 使用方式

1. 打开问卷入口，填写昵称（可留空）和可选性别标记。
2. 完成全部 20 题，每题选择 1–5 的同意程度。
3. 可选填写一条匿名留言，提交后进入档案索引。
4. 在索引中查看自己的六维画像，以及与其他匿名档案的相似度。

量表仅用于调查和界面展示。匹配结果不是交友推荐、伴侣筛选、心理评估或专业建议，不应据此作出重要个人决定。

## 数据与隐私

服务端仅保存以下内容：

- 随机档案编号与提交时间；
- 20 个 1–5 的量表回答；
- 自填昵称或系统生成的访客名称；
- 可选留言与性别标记。

系统不要求姓名、学号、联系方式、精确位置或账号信息。请勿在昵称或留言中填写自己或他人的个人敏感信息。

已提交的匿名档案会出现在公共匹配索引中。若准备将本系统用于正式研究、课程作业或公开招募，请先根据当地要求补充知情同意、数据保留期限、删除渠道及必要的伦理审查说明。

## 运行

需要 Node.js 22.12 或更高版本，以及支持 WebGL 2 的现代浏览器。

```sh
npm ci
npm run dev
```

开发服务器默认在 `http://127.0.0.1:5173/` 提供页面。构建生产版本：

```sh
npm run build
npm run preview
```

## 问卷接口

生产接口为：`https://query.linxiksp.cn/api/survey`

前端可以在构建时通过 `VITE_SURVEY_API_URL` 指向其他 HTTPS 接口：

```sh
VITE_SURVEY_API_URL=https://example.com/api/survey npm run build
```

接口约定：

- `GET /api/survey`：返回最多 500 条匿名档案。
- `POST /api/survey`：接收 `answers`（20 个 1–5 整数）、`label`、`message` 与 `gender`。
- 旧记录若缺少留言或性别，服务端与前端都会补充安全默认值，确保历史问卷仍可展示。

仓库同时包含两种服务端实现：

- [`server/index.mjs`](server/index.mjs)：自托管 Node 服务，适合由 Nginx 等反向代理暴露 HTTPS 接口。
- [`functions/api/survey.ts`](functions/api/survey.ts)：Cloudflare Pages Function，可绑定 D1 数据库。

自托管服务示例：

```sh
npm run build
npm run start:server
```

运行时可用 `PORT`、`SURVEY_DATA_DIR` 与 `SURVEY_ROOT` 分别指定端口、提交数据目录和项目根目录。反向代理应将 `/api/survey` 转发到 Node 服务，并保留 `GET`、`POST` 与 `OPTIONS` 请求。更多说明见 [问卷后端部署](docs/SURVEY-BACKEND.md)。

## 技术构成

- TypeScript、Vite、Three.js
- 浏览器 `localStorage` 本地回退
- Node.js JSON 存储或 Cloudflare Pages Function + D1
- PWA 离线资源与可安装入口

三维场景、开场动效与模型查看器来自原项目的界面体系；问卷、匿名档案、画像、匹配逻辑和后端接口为本项目的改造范围。
