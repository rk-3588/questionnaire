# 问卷 v2：题目、回答版本与展示

版本：2026-11-03。范围为高校在读学生，包含专科、本科、硕士、博士与已婚学生。

## 已实现

- 共享题库 `src/questionnaire.ts`：B1—B4、Q1—Q20、S1—S2；文档通过 `npm run export:questionnaire` 从同一题库生成。
- 保留意愿、过去行动、未来计划、现实因素、情景选择与支持需求的区别。Q7 删除双方自愿的重复条件；Q12 聚焦住房安排；Q13、Q14 明确首先或优先考虑；Q15 单独询问讨论程度；S1 不预设非婚育儿。
- 已婚分支跳过十道针对本人未来结婚安排的题；未婚有伴侣仅跳过 Q4；当前单身不自动跳过 Q3、Q15。
- `schemaVersion: 2`、`questionnaireVersion: 2026-11-03`；按固定题号保存选择、状态与跳题原因。多选不是有序排名，类别题不转成分数。
- 取消六维图和匹配百分比，显示回答概览及按章节展开的原题原答。旧二十题保留版本 1，不套用新题。
- 正确区分本人的提交与公共访客；草稿、未同步副本与本人编号均存于本机。SYSTEM 详情按实际档案 ID 获取记录，不再回退到当前访客的身份。
- 默认不公开个人档案；选择公开时仅开放昵称与选择题回答，开放题和其他补充文字始终从 GET 投影中移除。
- Node 与 D1 共用校验，Node 串行及原子写入、同编号重试防重、失败不覆盖原文件，公共 500 条限制不截断历史存储。
- 问卷遮挡画面时暂停三维更新，隐藏其画布，返回 SYSTEM 后恢复；原模型及场景参数不修改。

## 发布与回退

应先将支持 v2 的 Node 服务部署，再发布新页面。Node 可继续读取原 `SURVEY_DATA_DIR`，不需要改写旧记录。D1 使用新增表迁移 `0003_questionnaire_v2.sql`，须在 Function 发布前执行；当前生产采用 Node，不自动修改未启用的 D1 实例。

保留旧静态包和旧服务入口，便于回退前端。若回退旧服务，其旧版写入逻辑可能截断或过滤 v2 数据；有新版实际提交后应继续使用兼容服务，仅回退前端。提交数据备份保存在站点静态目录之外。
