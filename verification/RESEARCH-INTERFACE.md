# 正式婚恋调查界面验证

日期：2026-11-05。产品与视觉范围见 [界面规范](../docs/RESEARCH-INTERFACE.md)。题库与数据版本继续为 `2026-11-03`。

## 实现

- 正式入口改为 `src/research-app.ts`，首页、问卷、提交记录和调查说明直接导航。调查说明为独立页面，只展示填写、提交及回答使用指南；首页保持主题与参与入口。
- 暖白纸面、深蓝主色、灰绿选择状态和少量浅陶色装饰，系统字体。图标从 SVG 源码可复现导出。
- 正式页面没有 WebGL 场景、模型查看器、开场授权、游戏、背景音乐、解密文字或滚动数字。仅保留 150—260ms 的轻微过渡，尊重系统减少动态效果设置。
- 本人提交按原 ID 识别，公共记录来自原 API，不再将四十份原项目示例放入正式网站。新版与旧版仍显示各自原题；默认私密和补充文字隔离规则延续。
- 草稿及提交副本沿用原存储键。失败提交可导出、重试，同一编号不会重复写入。
- 正式构建仅打包所需资源。当前 PWA 完整离线文件 9 个，共 100,360 字节；不复制或缓存旧模型、音频、字体和静态示例。
- Cloudflare 打包适配新资源清单，保留历史字体包校验分支。独立 Wallpaper Engine 构建在 HTML 解析前切回原 `src/main.ts`，并验证打包的是原场景入口。
