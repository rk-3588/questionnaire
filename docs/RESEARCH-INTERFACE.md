# 大学生婚恋调查界面

2026-11-05 按用户要求，将正式网站从游戏式档案终端改为调查网站。沿用原生 TypeScript 与 CSS 实现；问卷题目及数据协议延续版本 `2026-11-03`。

## 页面与内容

- 首页介绍调查主题、对象、题目构成、参与方式和隐私范围。导航直接进入填写问卷、提交记录及调查说明。
- 逐题填写使用常规单选、多选、文本输入和进度条。已有草稿可在同一浏览器继续；更换基本情况后仍由共享题库计算适用范围。
- 提交记录显示本机自己的提交与接口中的公开回答，逐条标明版本与归属。详情直接展示实际选择的记录；不使用原项目的四十份静态示例。
- 安装与更新通过原生对话框打开，更新资源就绪时提供显式更新按钮。更新页从网络读取，延续原 Service Worker 的版本切换协议与浏览器存储键。

首页用静态相交线条表达个人成长、亲密关系与共同生活的联系，仅作装饰，不表示统计结果。标题使用系统宋体衬线字体，正文使用系统中文无衬线字体。配套图标为原生 SVG 文档符号，由 `scripts/build-survey-icons.mjs` 可复现生成主屏幕 PNG。

桌面使用留白与并列内容，宽度在 760px 以下切为单列。手机保留常规页面滚动和固定顶部导航，输入框字体 16px，避免 iOS 输入时自动放大。

## 动态与资源

首页首次淡入 260ms；按钮、选项和进度条过渡约 150—180ms。没有循环背景动画、开机授权、文字解密、镜头移动、音效或背景音乐。系统启用减少动态效果时关闭这些过渡。

正式构建从 `src/research-app.ts` 进入，Vite 仅打包新页面及其公共资源，不复制原游戏模型、静态档案、音频或字体。PWA 缓存包含本次页面完整资源；提交接口仍从网络读取。正式入口无需 WebGL。

原三维源代码、美术源文件、许可证及原项目署名保留。`build:wallpaper` 独立构建通过 Vite 切回 `src/main.ts`，沿用原场景。此任务不代表发布或重新验收 Wallpaper Engine。

## 数据延续

本次不改变题库、后端接口、历史记录或公开规则。问卷草稿、本人记录和公共缓存沿用 `rhine-survey-v2-draft`、`rhine-survey-v2-records`。提交失败仍只在本机暂存，可导出并按同一编号重试。

本机视觉与运行验证见 [验证记录](../verification/RESEARCH-INTERFACE.md)。
